# Proyecto: Gemelo Digital de Parque Eólico
## Integrantes:
* Stefany Nuñez
* Gerardo Zapana 
* Eduardo Fabian
* Santiago Saravia

## Descripción:
Este proyecto es un Gemelo Digital desarrollado en C++ y Qt (QML) para la simulación y monitoreo de un parque eólico, incluyendo alertas visuales según las condiciones del viento.
